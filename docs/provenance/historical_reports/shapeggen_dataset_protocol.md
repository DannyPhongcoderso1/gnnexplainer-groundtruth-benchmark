## Upstream Generator Parameters

These values are passed to official GraphXAI `ShapeGGen`.

| Parameter | Frozen value | Role |
|---|---:|---|
| `model_layers` | `3` | Explanation enclosing-subgraph hop depth |
| `shape` | `house` | Motif inserted by ShapeGGen |
| `seed` | `912` | Upstream graph and feature seed |
| `make_explanations` | `true` | Generate official target GT explanations |
| `variant` | `1` | Preferential-attachment ShapeGGen variant |
| `num_subgraphs` | `100` | Number of motif-centered subgraphs |
| `prob_connection` | `0.09` | Inter-subgraph connection probability |
| `subgraph_size` | `13` | Expected subgraph size before interconnection |
| `verify` | `true` | Use upstream motif verification loop |
| `max_tries_verification` | `15` | Upstream verification retry limit |
| `n_informative` | `6` | Informative structured feature count |
| `class_sep` | `0.5` | Structured feature class separation |
| `n_features` | `10` | Feature count before optional sensitive feature |
| `n_clusters_per_class` | `2` | Structured feature clusters per class |
| `homophily_coef` | `null` | No upstream homophily optimization |
| `add_sensitive_feature` | `false` | No sensitive feature appended |
| `attribute_sensitive_feature` | `false` | Inactive because sensitive feature is disabled |
| `sens_attribution_noise` | `0.25` | Inactive because sensitive feature is disabled |

`flip_y` is not in the frozen config because official `ShapeGGen` does not expose
it in the constructor. Unsupported config fields fail fast.

## Local Adapter Parameters

| Parameter | Frozen value |
|---|---|
| `edge_representation` | directed PyG edge entries from upstream graph |
| `ground_truth_storage` | target-specific dense masks from official explanations |
| `feature_explanations_in_core_metrics` | `false` |
| split method | `stratified_disjoint` |
| split seed | `912` |
| train ratio | `0.6` |
| validation ratio | `0.2` |
| test ratio | `0.2` |

The graph and ground-truth explanations are generated by official GraphXAI
ShapeGGen. Train/validation/test splitting is performed locally for the thesis
benchmark because upstream GraphXAI uses independently sampled split masks that
can overlap.

motif, and class `1` means two nearby unique motifs. They are not BA-House labels

## Edge Terminology

Use “directed edge entries” for PyG `edge_index`. In this artifact, 4,518
directed edge entries correspond to 2,259 undirected edges stored with reverse
entries. Reverse-edge coverage is complete, there are no self-loops, and there
are no duplicate ordered edge entries.
