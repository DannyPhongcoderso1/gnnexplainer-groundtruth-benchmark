## Findings and unresolved description gaps

1. **GNN feature-mask scope is underdescribed**, not an architecture rewrite: configs/shared/gnnexplainer.yaml enables node_mask_type=common_attributes as well as an object edge mask; canonical GNN source passes both to PyG. Elliptic config/runner does likewise. The thesis focuses on edge-level outputs in3.4.1 but does not disclose the joint feature-mask optimization. Do not interpret accepted results as proof of an edge-only optimization process. No mask configuration was changed.
2. **Cross-dataset PG evaluation is not identical postprocessing.** Synthetic evaluators use explanation.edge_mask from PyG (postprocessed sigmoid scores: pg_explainer.py315-327); historical Elliptic RAW replay directly scores the MLP as float32. Mathematical sigmoid monotonicity does not guarantee float32 ranking/tie equivalence under saturation. The thesis's same-implementation statement describes the shared learner but omits this evaluation adaptation. Existing accepted results and diagnostic probes remain separate.
3. **FRESH5 tie handling is an evaluation-only addendum.** Historical seed42 uses original torch.topk RAW selection; FRESH5 uses exact RAW ties broken by ascending global directed edge ID in evaluate_task29_tie_v1.rank:43-55. The thesis's general20% rule does not specify this distinction. No seed42/FRESH5 relabeling or global adoption of the diagnostic tie policy was performed.
4. **Temperature endpoint precision:** locked PyG455-457 uses5*(2/5)^(epoch/30), while training epochs are0..29. Configuration names endpoint2; the last trained epoch does not reach exactly2. Thesis3.4.2 says5 to2; interpreting that as an exact final-epoch value is an overstatement. No schedule was changed.
5. **Optimizer construction documentation corrected.** PyG constructor line88 creates Adam. The model-only adapter delegates to that constructor, so earlier wording that it creates no optimizer was false even though it performs no optimizer step. Current docstrings/guide now distinguish construction from stepping/restoration. This audit did not call the constructor or execute any optimizer.
6. **Known BA500 cohort conflict remains unresolved.** Common48/16 versus natural106/35 lineage and nine withheld cells are preserved. Source cleanup cannot settle which thesis numbers should represent which cohort; it does not substitute measurements.
